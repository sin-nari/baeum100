# 부천 배움100이음

2026 부천 고교학점제 성장 이야기 「부천 배움100이음」 안내 사이트입니다.

## 고치는 곳
`index.html` 아래쪽 `<script>`의 운영 설정만 고치면 됩니다.

- `PRESS` — 언론 기록 11건. `url: ""` 안에 기사 주소를 넣으면 '기사 보기' 버튼이 켜집니다.
- `DOCS` — 책자 PDF 주소를 `url`에 넣으면 다운로드 카드가 켜집니다.
- `PAGES` — 책자 면 목록(표지~뒷표지 13장).

## 책자 이미지 교체
`assets/pages/p01.jpg` ~ `p13.jpg`(펼침면)와 `_t.jpg`(썸네일)를 최종본으로 같은 이름으로 덮어쓰면 됩니다.
